# What people complain about in other apps — and Cariño's answer

Source themes: `docs/RESEARCH-SYNTHESIS.md` (store reviews, review analyses,
X sentiment, Nov 2026). Use the right-hand column in store listings, review
notes and the venue/partner kit. Only claim what is shipped (✅); keep 🔜 out
of marketing until it is live.

| What people complain about elsewhere | Cariño's answer | State |
|---|---|---|
| "Bots and fake profiles everywhere" | 3-layer ID + liveness verification, 21+; Dates is verified-only | ✅ |
| "Conversations die / one-word replies" | **You both** chips (real shared tastes), openers built from them, games | ✅ new |
| "I can't tell if they're slow or not interested" | **How I text** card + pace note ("Aria usually replies in the evening") | ✅ new |
| "Ghosting" | **Pause, don't ghost** (one tap: "back next week"), Close the Loop | ✅ new |
| "Unwanted photos / pushy calls" | **Comfort rules** enforced by the app and the server: photos after N days, no calls before meeting, daytime first meet | ✅ new |
| "Texts read wrong / sarcasm lands badly" | Optional **tone tags** (joking, serious, being gentle, excited) | ✅ new |
| "We chat for weeks and never meet" | Plans engine; a shared interest in chat suggests a bookable plan ("You both like coffee… Phone-free café hour") | ✅ new |
| "I forget who's who" | **Things to remember**: a private note per match, shown in that chat | ✅ new |
| "The algorithm doesn't learn what I like" | Private after-date check-in reorders *your* suggestions, with the reason shown | ✅ new |
| "Doom-scrolling, endless swiping" | Finite feed, Daily Drop, No-Counts mode, Phone-Down Mode | ✅ |
| "Language barriers" | Translate on any message (labelled; needs the live AI key) | ✅ app · 🔑 key |
| "Paywalled safety" | Report, block, check-in and Scam Shield are free, always | ✅ |
| "AI is fake / talks for people" | AI only drafts; the member sends. Away assistant is labelled | ✅ |
